E-Learning Project

Repositori ini sekarang telah dipush ke GitHub.

GitHub Pages dapat menampilkan halaman statis, tapi tidak dapat menjalankan PHP/MySQL yang digunakan oleh aplikasi ini.

Jika kamu ingin aplikasi e-learning berjalan online, gunakan hosting PHP/MySQL (misalnya Hostinger, Niagahoster, atau cPanel hosting).

Untuk GitHub Pages, halaman ini adalah placeholder statis.

Jika kamu mau, saya bantu bikin landing page statis atau bantu deploy aplikasi ke hosting PHP.
